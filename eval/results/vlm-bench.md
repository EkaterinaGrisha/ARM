# Локальные мультимодальные модели на одних задачах

Получено `uv run python eval/vlm_bench.py --score --model qwen/qwen3.6-27b --model google/gemma-4-e4b --text-model paddleocr-vl-1.6=bench_ocr_paddle.v1` 2026-11-02; Darwin arm64, Python 3.11.15; tesseract 5.5.2.
Модели загружались по одной на локальном сервере, полностью — [vlm-bench.json](vlm-bench.json).

Листы — 17 реальных сканов эталона, чаще всего не по ГОСТ 2.104: модель с JSON-схемой заполняет поля, OCR-модель выдаёт текст листа. ТТ и ячейки — синтетические растры и сканы, вырезанные по рамке разметки, поэтому поиск области не измерен и это верхняя граница. Значения сравниваются по правилу `eval/gold.py`. «В ответе» — значение целиком есть в тексте ответа, «выдумано» — непустое значение там, где на листе поля нет. Параметры ТТ — категории, которые пишутся только в блоке; часть их формулировок ядро не знает (пробелы этапа 5), поэтому 100 % здесь недостижимы ни для кого.
