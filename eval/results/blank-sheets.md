# Пустые листы

Получено `uv run python eval/blank_sheets.py --pages 40 --arm dev test` 2026-11-05; Darwin arm64, Python 3.11.15, 517.3 с. Пустым загрузчик ядра считает лист без текста, у которого на копии 3 пкс/мм без полос по 12 мм у краёв отметки есть не больше чем в 2 клетках по 20 мм. Отметка — деталь уже 5 пкс копии, на 10 уровней серого темнее бумаги вокруг; клетка с отметками — от 1% её площади. Страница меньше 9 клеток — не лист: заглушка или картинка, она меряется целиком (`blank` в configs/ingest.yaml); полностью — [blank-sheets.json](blank-sheets.json).
