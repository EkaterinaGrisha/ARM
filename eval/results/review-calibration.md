# Отметка «проверить»: калибровка порога уверенности

Получено `uv run python eval/review_calibration.py --target 0.02`. Значение отмечено, если оно взято из имени файла, если два прочтения разошлись (статус `conflict`) или если его уверенность ниже порога. Считаются значения растров и сканов, которые отчёт дал: основные надписи, строки спецификаций, пункты ТТ комплекта `arm-1` ([arm-gold-arm-1.md](arm-gold-arm-1.md)) и замороженного синтетического корпуса ([reading-errors.md](reading-errors.md)) без стрессовой части. Документы поделены пополам по sha256 корпуса, комплекта и имени: на первой половине выбран наименьший порог сетки, при котором среди неотмеченных значений неверных не больше 2%; вторая половина его проверяет. Интервал — 95 % бутстрепом по документам второй половины. До калибровки отмечено каждое значение OCR и модели.
