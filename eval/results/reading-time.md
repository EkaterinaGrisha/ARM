# Время чтения комплектов по числу процессов

Получено `uv run python eval/reading_time.py` 2026-11-20; Darwin arm64, Python 3.11.15, ядер 10, tesseract 5.5.2, модель qwen3.6-35b-a3b-mlx. Ядро читает с OCR и без кэша прочтений. Полностью — в [reading-time.json](reading-time.json).

Чтение: «процессы» и «потоки» — файлы комплекта читают столько процессов или потоков, модель выключена; «модель» — модель включена, файлы читают процессы по умолчанию, а число — запросы к модели сразу. Время — весь прогон ядра по комплектам цели. Ускорение — к числу 1 того же чтения: «потоки» — к одному процессу. «Отчёт тот же» — отчёты, совпавшие целиком, без времени обработки: без модели — со снимком [snapshots.py](../snapshots.py), с моделью — с отчётом при одном запросе сразу.
