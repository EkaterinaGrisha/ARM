# Эталон на реальных документах

Два набора из корпуса открытых чертежей ([open_drawings.csv](../open_drawings.csv)), пока нет комплектов АРМ: учебные комплекты для Блока 1 — что лежит в каждом файле и какие расхождения должна найти проверка, и отдельные листы производственной КД — что записано в основной надписи. Формат — `KitTruth` из [synth/truth.py](../../synth/src/synth/truth.py), как у синтетических комплектов: отчёт с обоими сравнивает один и тот же код.

Сами документы лежат в `data/` вне git, разметка — здесь. Разметку комплектов АРМ в git не кладём: в ней данные заказчика.

## Что размечено

| Где | Что |
| --- | --- |
| `root` | обозначение изделия верхнего уровня, без кода документа; `""`, если обозначения нет |
| спецификация | из основной надписи: `designation`, `name`, `litera`, `revision` — номер последнего изменения, `sheets`; строки — в `rows` |
| строка спецификации | `section` — раздел над строкой; `fmt`, `pos`, `designation`, `name`, `qty`, `note` — как в графах |
| чертёж | `designation`, `name`, `litera`, `revision`, `sheets`; также `material`, `mass`, `scale`, `archive_number`, `first_use` — по ним проверим основную надпись в Блоке 2 |
| схема, перечень элементов, чертёж общего вида | вид `other`: `designation`, `name`, `litera`, `revision`, `sheets` |
| лист набора листов | основная надпись, как у чертежа; вид — из `sheets.csv` |
| `problem_files` | файл, который не документ комплекта: 3D-вид, титульный лист, технологический документ — статус `foreign` |
| `discrepancies` | расхождения, которые должна найти проверка: `type`, `designation`, `comment` — почему расхождение есть |
| `notes` | спорные случаи комплекта и решения по ним, по строке на случай |

Вид документа — по самому документу: чертёж общего вида модуля питания реестр относит к сборкам, в разметке он `other`. Технические требования (`requirements`, `parameters`) пока не размечены.

## Как записаны значения

- Как на листе: ошибки автора не исправлены, опечатка остаётся в значении — «песпаечных плат» на листах А1 модуля питания.
- С изображения листа, а не из текстового слоя PDF: у части файлов слой битый. У модуля питания кириллица в нём — байты UTF-8, прочитанные как UTF-16.
- Наименование в основной надписи — все строки графы через пробел, изделие и документ: «Паяное соединение Сборочный чертеж».
- Перенос строки внутри графы — один пробел, двойной пробел — один.
- Пустая графа — `""`; графы нет на бланке — `null`: у бланков ВЛ60 нет материала, масштаба и литеры, у «Наружных видов» УЭП-60-10 — ничего, кроме наименования и обозначения.
- Записанное не в своей графе — значение той графы, где оно стоит: в графе обозначения листов ИЖ-250 — наименование станка.
- Зачёркнутое — не значение: значение — действующая запись рядом с ним.
- Перенос слова с дефисом — слово целиком: «элек-тропитающее» — «электропитающее». Рукописные сокращения — как написаны: «Ток. винторезн.».
- Регистр, «ё», десятичная запятая, тире, кавычки и латинские буквы, похожие на русские, — как набраны: сравнение их не различает.
- Наименование на нескольких строках спецификации — одна строка `rows`, части через пробел.
- `section` — подчёркнутый заголовок над строкой: «Документация», «Сборочные единицы», «Детали», «Стандартные изделия», «Прочие изделия», «Материалы».

## Какие расхождения размечены

Расхождение размечено, если технолог на входном контроле вернул бы его конструктору. Типы и правила — из [каталога](../../docs/report-format.md#правила-блока-1-discrepanciesrule_id). В `designation` — обозначение позиции или документа, к которому относится расхождение; если обозначения нет — `""` и наименование в `name`.

| Тип | Когда | Пример из этих комплектов |
| --- | --- | --- |
| `missing_drawing` | позиции из «Деталей» или документа из «Документации» нет в комплекте; позиции «БЧ» не в счёт | ИТМО: у деталей СУИР.06.06.04–08 нет чертежей; модуль питания: корпусные детали |
| `orphan_drawing` | документ комплекта не указан ни в одной спецификации | ИТМО: сборочный чертёж, «Документации» в спецификации нет; модуль питания: перечень элементов |
| `name_mismatch` | наименование на чертеже отличается от спецификации больше, чем регистром, «ё» и пунктуацией; у документов из «Документации» сравнивается наименование изделия | модуль питания: «…для песпаечных плат…» на листах А1, «…для беспаечных макетных плат…» в спецификации |
| `duplicate_designation` | одно обозначение у разных документов или у позиций с разными наименованиями | ЛЭТИ: ПМИГ 2208.23.001 — «Основание» и «Кожух»; ИТМО: спецификация обозначена СУИР.06.06.00.СБ, как сборочный чертёж |
| `revision_mismatch` | разные литеры или номера изменений у документов одного изделия | |
| `missing_specification` | у сборочной единицы нет своей спецификации | модуль питания: печатная плата |
| `position_anomaly` | у позиции нет обозначения или количества, номер позиции повторяется; в отчёте такого типа ещё нет. Не аномалия: стандартные и прочие изделия и материалы без обозначения и пропущенные номера — ГОСТ 2.106 допускает их резервировать | модуль питания: позиции 1–3 без обозначений |

Остальные типы плана — `format_mismatch`, `sheets_missing`, `section_mismatch`, `first_use_mismatch` — в разметке допустимы, хотя правил для них у ядра пока нет; в этих комплектах их нет.

## Двойная разметка

ИТМО и ЛЭТИ размечены дважды, независимо: 16 листов из 23, больше 15–20 %, которые требует план. Модуль питания размечен один раз. Согласие считается по значениям, которые есть хотя бы в одной разметке, после нормализации ([results/gold-agreement.md](../results/gold-agreement.md)): ИТМО — 1,00 (93 из 93), ЛЭТИ — 0,94 (147 из 156). Из девяти несовпадений ЛЭТИ восемь — значения, которых нет в одной из разметок: корень, основная надпись спецификации «Паяного соединения», расхождения; одно — прочтение, «Кажух» вместо «Кожух». Каждое несовпадение решено по листу.

Из набора листов дважды размечены 5 из 22, самые трудные: две рукописные надписи ИЖ-250, два бланка ВЛ60 — PDF со слоем распознавания и картинка — и упрощённая надпись испытательного прибора. Сравниваются только листы, которые есть в обеих разметках. Совпало 24 значения из 27 (0,89), без вида и числа листов, которые обе разметки берут из `sheets.csv`, — 14 из 17. Из трёх несовпадений два — прочтения, «Коробка вывода» и «Секия якоря», одно — черта от руки в «ИЖ-250», записанная пробелом. Каждое решено по листу.
