# Техническая документация проекта

Сервис входного контроля конструкторской документации для АРМ. На входе — папка с PDF и JPG: спецификации, сборочные чертежи, чертежи деталей. На выходе — отчёт по двум блокам кейса ([CASE.md](CASE.md)): комплектность с деревом изделия и расхождениями и таблица параметров деталей с отметками критичности. Каждое значение отчёта ссылается на лист и область, откуда оно взято.

## Из чего состоит

| Часть | Где | Что делает |
| --- | --- | --- |
| Ядро | `packages/kdcheck` | Вся логика: чтение файлов, основная надпись и спецификация, дерево изделия, правила Блока 1, параметры и критичность Блока 2, выгрузки; CLI `kdcheck run` |
| API | `backend/arm_web` | FastAPI: принимает комплект, запускает `kdcheck run` отдельным процессом с лимитами, отдаёт отчёт |
| Веб | `frontend/` | React: загрузка, прогресс, отчёт по вкладкам, лист с подсветкой источника значения |
| Генератор | `synth/` | Синтетические листы и комплекты по ГОСТ с разметкой и заложенными ошибками |
| Замеры | `eval/` | Скрипты замеров, их результаты и эталон на реальных комплектах |
| Настройки | `configs/` | Пороги, формы ГОСТ, словари, правила, движки, лимиты |

Подробно — [ARCHITECTURE.md](ARCHITECTURE.md), формат отчёта и каталог правил — [report-format.md](report-format.md), запуск — [README.md](../README.md).

## Подход

- Сначала правила: геометрия форм ГОСТ 2.104 и 2.106, текстовый слой PDF, регулярные выражения. Сканы читает Tesseract, дальше те же правила. Модель добавляется, только если замер показал выигрыш: мультимодальная модель на локальном сервере дочитывает основные надписи сканов за флагом `--vlm` ([ADR-0014](adr/0014-local-vlm.md)).
- Плохой файл или лист не останавливает прогон: он попадает в отчёт со статусом и причиной.
- Пороги, шаблоны и словари — в `configs/*.yaml`; отчёт хранит версии движков и хэш настроек.
- PDF читает pypdfium2 (Apache/BSD). PyMuPDF (AGPL) в поставку не входит, его ставят отдельно для сравнения и отката ([ADR-0007](adr/0007-pdf-library.md)).

## Данные

Документы в git не хранятся: `data/` — в `.gitignore`, лицензии открытых чертежей разрешают только внутреннюю оценку, комплекты АРМ — данные заказчика.

| Данные | Где | Как получить |
| --- | --- | --- |
| Открытые чертежи и учебные комплекты | `data/open_drawings/`, реестр — [eval/open_drawings.csv](../eval/open_drawings.csv) | `uv run python eval/open_drawings.py fetch` скачивает по реестру и сверяет sha256; источники — [DATA_SOURCES.md](DATA_SOURCES.md) |
| Синтетические комплекты | `data/synth/` | `uv run python -m synth.kits data/synth/kits --kits 20 --seed 1` |
| Стрессовый корпус: те же комплекты со сканами через Augraphy | `data/synth/stress/`, манифест — [eval/stress_corpus.json](../eval/stress_corpus.json) | `uv run --group augraphy python -m synth.stress build data/synth/stress` на Python 3.11; файлы сверяет `uv run python -m synth.stress verify data/synth/stress` |
| Комплекты АРМ | `data/` | по правилам АРМ, вне git |
