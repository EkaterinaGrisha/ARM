# Источники реальных чертежей ЕСКД

Практический список мест, где искать чертежи для обучения и тестирования.

## Патентные базы (лучший источник)

### Google Patents
**URL:** https://patents.google.com/

**Как искать:**
```
Поисковые запросы:
- "Russia" "GOST" drawing
- RU патенты с фильтром по стране: RU
- Конкретные термины: "вал", "корпус", "редуктор", "фланец", "кронштейн"
- Полезные модели часто содержат подробные чертежи
```

**Что искать:**
- Российские патенты (RU) с 2010+ года — чаще векторные PDF из САПР
- Раздел с чертежами обычно называется "Drawings" или "Фигуры"
- Скачивай PDF патента, извлекай страницы с чертежами

**Лицензия:** Патенты — публичная информация, но для коммерческого использования уточняй

### ФИПС (Федеральный институт промышленной собственности)
**URL:** https://www1.fips.ru/

**Как искать:**
- Раздел «Открытые реестры»
- Поиск по изобретениям и полезным моделям
- Фильтры: дата подачи (новее = лучше качество), МПК класс (например, F16 — машиностроение)

**Что качать:**
- Описание изобретения (PDF)
- Смотри раздел "Чертежи" или "Графические материалы"

### Espacenet (Европейское патентное ведомство)
**URL:** https://worldwide.espacenet.com/

**Как искать:**
```
Advanced search:
- Publication number: RU* (российские патенты)
- Keywords: GOST, ЕСКД, или технические термины на русском
```

**Преимущество:** Удобный поиск по техническим классам (IPC)

```
│   ├── bmstu/

│   └── other/
├── github/                   # Из открытых репозиториев
├── forums/                   # С форумов
└── catalogs/                 # Каталоги производителей
```

### Формат registry.csv

```csv
filename,source,source_url,license,doc_type,quality,has_title_block,has_spec,notes
patent_RU2734567_fig1.pdf,Google Patents,https://patents.google.com/patent/RU2734567,public_patent,part,vector,yes,no,"Вал редуктора, хорошее качество"
bmstu_bearing_housing.pdf,BMSTU,https://bmstu.ru/...,educational_use_only,assembly,vector,yes,yes,"Учебный пример курсового"
```

**Поля:**
- `filename` — имя файла
- `source` — откуда взят (Google Patents, FIPS, BMSTU, GitHub, etc.)
- `source_url` — прямая ссылка
- `license` — лицензия или ограничения (public_patent, educational_use_only, unknown, etc.)
- `doc_type` — part (деталь), assembly (сборка), specification, title_block_only
- `quality` — vector, raster_clean (чистый скан), raster_poor (плохой скан)
- `has_title_block` — yes/no
- `has_spec` — yes/no (есть ли спецификация в документе)
- `notes` — любые комментарии

## Целевые показатели

**Минимум для начала (этап 4):**
- 50 листов: 30 векторных + 20 сканов
- Типы: 25 деталей + 15 сборок + 10 спецификаций
- Для теста OCR: 20-30 листов с размеченными основными надписями

**Цель для полноценной оценки (этап 8):**
- 150+ листов
- Стратифицированная выборка: векторные/сканы × тип документа × качество
- 15-20% двойная разметка для проверки согласованности

## Важные напоминания

1. **Лицензии:** Большинство найденных материалов — только для внутренней оценки. Не публикуй чужие чертежи в открытом репозитории без разрешения.

2. **Качество важнее количества:** Лучше 50 качественных и разнообразных листов, чем 200 однотипных.

3. **Ведение реестра обязательно:** Потом невозможно вспомнить, откуда что взялось.

4. **Проверяй актуальность ГОСТ:** В 2024 году ГОСТ 2.104-2006 заменён на ГОСТ Р 2.104-2023. Старые чертежи могут иметь другие формы основных надписей.

5. **Разнообразие форматов:** Собирай не только A4, но и A3, A2, A1 — алгоритм должен работать на всех форматах.

6. **Разные САПР:** Чертежи из КОМПАС-3D, AutoCAD, SolidWorks могут иметь разные особенности текстового слоя PDF.
