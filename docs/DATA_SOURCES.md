# Источники реальных чертежей ЕСКД

Практический список мест, где искать чертежи для обучения и тестирования.

## Что собрано

Задача команды от 26.10.2026: не меньше 200 чертежей разных лет, включая советский период. Поиск разделён, чтобы не дублировать:

| Кто | Где ищет |
| --- | --- |
| Аня | Патентные базы и интернет |
| Катя | Электронные архивы и библиотеки (archive.org), стандарты ЕСКД разных редакций, вузовские методички, GitHub |

Реестр — [eval/open_drawings.csv](../eval/open_drawings.csv), одна строка на документ: ссылка, год, период стандартов оформления, категория, число страниц и листов, sha256. Файлы лежат в `data/open_drawings/` вне git: лицензии разрешают только внутреннюю оценку. `uv run python eval/open_drawings.py fetch` скачивает по реестру то, чего нет, и сверяет хэши; `summary` пишет сводку в [eval/results/open-drawings.md](../eval/results/open-drawings.md). Копия корпуса — в закрытой папке команды на Google Диске, `ARM/data/open_drawings`: она нужна, если ссылка из реестра перестала работать.

На 26.10.2026 в реестре 82 документа, 5503 страницы. Листов производственной КД с основной надписью — 506, их сосчитали глазами по миниатюрам всех страниц:

## Патентные базы

Ограничение: чертежи в патентах выполняют по правилам оформления заявок, без рамки, основной надписи, спецификации и технических требований. Для извлечения полей основной надписи и спецификации они не годятся, для распознавания поля чертежа подходят.

### Google Patents
**URL:** https://patents.google.com/

**Как искать:**
```
Поисковые запросы:
- "Russia" "GOST" drawing
- RU патенты с фильтром по стране: RU
- Конкретные термины: "вал", "корпус", "редуктор", "фланец", "кронштейн"
- Полезные модели часто содержат подробные чертежи
```

**Что искать:**
- Российские патенты (RU) с 2010+ года — чаще векторные PDF из САПР
- Раздел с чертежами обычно называется "Drawings" или "Фигуры"
- Скачивай PDF патента, извлекай страницы с чертежами

**Лицензия:** Патенты — публичная информация, но для коммерческого использования уточняй

### ФИПС (Федеральный институт промышленной собственности)
**URL:** https://www1.fips.ru/

**Как искать:**
- Раздел «Открытые реестры»
- Поиск по изобретениям и полезным моделям
- Фильтры: дата подачи (новее = лучше качество), МПК класс (например, F16 — машиностроение)

**Что качать:**
- Описание изобретения (PDF)
- Смотри раздел "Чертежи" или "Графические материалы"

### Espacenet (Европейское патентное ведомство)
**URL:** https://worldwide.espacenet.com/

**Как искать:**
```
Advanced search:
- Publication number: RU* (российские патенты)
- Keywords: GOST, ЕСКД, или технические термины на русском
```

**Преимущество:** Удобный поиск по техническим классам (IPC)

## Как организовать сбор

### Структура хранения

```
data/open_drawings/           # вне git; собирается по реестру командой fetch
├── archive_org/<id>/         # Электронный архив archive.org, папка на документ
├── standards/<ГОСТ>/         # Стандарты ЕСКД разных редакций
├── edu/<вуз_год_тема>/       # Методички вузов
├── github/<репозиторий>/     # Открытые репозитории
└── patents/<база>/           # Патентные базы
```

### Формат реестра

Реестр — [eval/open_drawings.csv](../eval/open_drawings.csv), строка на документ:

- `path` — путь внутри `data/open_drawings/`
- `source`, `source_url` — откуда и прямая ссылка на файл
- `title`, `year` — название и год документа; пусто, если год неизвестен
- `period` — период стандартов оформления: `pre_eskd`, `ussr`, `eskd_ussr`, `eskd_1992_2005`, `eskd_2006`, `eskd_2023`
- `category` — `production` (производственная КД), `catalog`, `educational`, `normative`
- `doc_type` — через `;`: `part`, `assembly`, `specification`, `scheme`, `list` (перечень элементов), `dimension` (габаритный чертёж), `form`, `text`
- `pages` — страниц в файле; `sheets` — листов с основной надписью, сосчитанных глазами; пусто, если не считали
- `quality` — `vector`, `raster` (растр без сканирования), `scan`, `photo`; `text_layer` — `native`, `ocr` (слой распознавания архива), `none`
- `license`, `sha256`, `added_by`, `notes`

## Целевые показатели

**Минимум для начала (этап 4):**
- 50 листов: 30 векторных + 20 сканов
- Типы: 25 деталей + 15 сборок + 10 спецификаций
- Для теста OCR: 20-30 листов с размеченными основными надписями

**Цель для полноценной оценки (этап 8):**
- 150+ листов
- Стратифицированная выборка: векторные/сканы × тип документа × качество
- 15-20% двойная разметка для проверки согласованности

## Важные напоминания

1. **Лицензии:** Большинство найденных материалов — только для внутренней оценки. Не публикуй чужие чертежи в открытом репозитории без разрешения.

2. **Качество важнее количества:** Лучше 50 качественных и разнообразных листов, чем 200 однотипных.

3. **Ведение реестра обязательно:** Потом невозможно вспомнить, откуда что взялось.

4. **Проверяй актуальность ГОСТ:** В 2024 году ГОСТ 2.104-2006 заменён на ГОСТ Р 2.104-2023. Старые чертежи могут иметь другие формы основных надписей.

5. **Разнообразие форматов:** Собирай не только A4, но и A3, A2, A1 — алгоритм должен работать на всех форматах.

6. **Разные САПР:** Чертежи из КОМПАС-3D, AutoCAD, SolidWorks могут иметь разные особенности текстового слоя PDF.
